About This Project

This website is deployed on AWS EC2 inside a custom VPC, automated via a GitHub Actions CI/CD pipeline. Every push to the main branch triggers an automatic deployment to this server.

What is DevOps & cloud ?

DevOps combines software development and IT operations to shorten the delivery lifecycle. It relies on automation, CI/CD pipelines, infrastructure as code, and continuous monitoring to ship reliable software faster.

Tech Stack

  • ☁️ AWS EC2 — Ubuntu 22.04
  • 🔐 AWS IAM — access management
  • 🌐 AWS VPC — custom network isolation
  • ⚙️ Nginx — web server
  • 🐙 GitHub Actions — CI/CD pipeline
  • 🚀 SSH + rsync — automated deployment
  • successful ec2 deployment

CI/CD Pipeline

Git Push → GitHub Actions → SSH to EC2 → Website Updated ✅
